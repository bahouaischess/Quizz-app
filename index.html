Comment ça marche ?

  1. Crée la matière avec son nom et son dossier.
  2. Ouvre-la depuis « Mes Matières ».
  3. Ajoute tes questions avec le bouton « Ajouter ».
  4. Les questions, statistiques et révisions seront sauvegardées sur ton compte.

Aucune modification du code n’est nécessaire. La matière restera disponible après actualisation et reconnexion.

Prompt conseillé pour une IA : « Remplis le modèle JSON QuizzHub avec mon cours. Respecte strictement le JSON valide, conserve les champs name, folder, description, prerequisites et questions, et utilise isCorrect: true pour chaque bonne réponse. N’ajoute aucun commentaire avec // ou /* */. »

Importer une matière avec ses questions

Télécharge le modèle, donne ton cours à une IA en lui demandant de respecter cette structure, puis importe le fichier JSON rempli.

Voir les règles acceptées
  • Le fichier doit être du JSON valide, sans commentaires JavaScript.
  • La matière doit avoir un nom et une liste questions.
  • Chaque question doit avoir un énoncé, au moins deux options, une bonne réponse et une explication.
  • Une option utilise isCorrect: true pour indiquer la bonne réponse.
